# IP-SAKTI Sahayak

AI-powered multilingual RAG-based assistant for Intellectual Property
and regulatory guidance in the AYUSH ecosystem.

## Problem

AYUSH innovators, researchers, practitioners and MSMEs often need to
navigate multiple overlapping IP, biodiversity and regulatory frameworks.

## Key Features

- 🇮🇳 India / 🌍 International Jurisdiction Switch
- 🤖 RAG-based AI assistance
- 📚 Source-grounded legal citations
- 📄 Document and page references
- 🧠 Formulation Classification
- 🌿 ABS Compliance Helper
- 🌐 Multilingual Support
- 🛡️ Safe Abstention
- 📊 Confidence Indicators
- ⚠️ Information, not legal advice

## Technology

- Frontend: HTML/CSS/JavaScript
- Backend: Python + FastAPI
- RAG: Python
- Database: PostgreSQL + pgvector
- AI: Gemini
- Deployment: Vercel + Render + Neon

## Architecture

Frontend → FastAPI → RAG → PostgreSQL/pgvector → Gemini
